# Security reporting

Please report a vulnerability privately through [GitHub's private reporting form](https://github.com/voltura/voltura-vault/security/advisories/new). Include the affected build, a description, and reproduction steps with synthetic data. Do not send passwords, exports, recovery files, or private keys.

Voltura Vault is an early source release. Security depends on the client device, the integrity of the web client host or installed build, access controls, and tested recovery.
